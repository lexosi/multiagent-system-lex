# venv info

Python virtual env del sistema multi-agente.

## Setup inicial (Lexosi: ya hecho)

```powershell
cd F:\multiagent-system
python -m venv .venv
.venv\Scripts\python.exe -m pip install openai
```

## Cómo invocar scripts wrapper

No activar venv. Usar path absoluto:

```powershell
F:\multiagent-system\.venv\Scripts\python.exe scripts\agents\<wrapper>.py "<args>"
```

Los agentes Claude Code "delegadores" llaman exactamente eso vía Bash tool.

## Dependencias actuales

- `openai` (DeepSeek API directa vía base_url override)

## Añadir nueva dependencia

```powershell
F:\multiagent-system\.venv\Scripts\python.exe -m pip install <package>
```

Actualizar esta lista tras instalar.
